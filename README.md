# Human Node Arcade

A mobile-first browser game prototype exploring human signals, reflex, and digital identity through a lightweight Web3-inspired experience.

## Overview

Human Node Arcade is an independent browser-based game project built as a small experiment around human interaction, signal, precision, and digital identity.

The current version focuses on a simple, playable experience rather than accounts, wallets, tokens, or backend infrastructure.

## Features

- Human Node Rush: 30-second reflex game
- Progressive difficulty during each run
- Chain multiplier scoring
- Best-score tracking
- Signal / noise / precision end-of-run statistics
- Local leaderboard stored in the player's browser
- Mobile-first responsive interface
- No backend
- No account system
- No wallet connection
- No token
- No external library

## Technology

- HTML
- CSS
- JavaScript
- GitHub Pages

## How It Works

The player completes a short reflex-based run.

During the run, the game tracks performance and applies progressive difficulty and multiplier-based scoring.

At the end of the run, the player receives performance statistics including signal, noise, and precision-related results.

Leaderboard data is stored locally in the player's browser.

## Run Locally

Open `index.html` directly in a browser, or serve the project directory using any simple local web server.

## Deployment

The project is deployed as a static website through GitHub Pages.
